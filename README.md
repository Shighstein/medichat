# medichat

A React + Vite chat application with a simple Node.js server.

It should run the project at `localhost:5173`

## Run the server

From the project root, start the server with:

```bash
node run server
```

The server will run on the port defined in the project configuration.

## Run the project locally

Start the frontend development server with:

```bash
npm run dev
```

This will launch the Vite development server, and you can open the local URL shown in the terminal in your browser.

## Install dependencies

If needed, install the project dependencies first:

```bash
npm install
```

## Current state
Right now, all it does is just talk to the AI. It's meant for a single user, hence, it does not support switching of users.
